# OIBSIP Python Programming Internship

This repository contains my work completed during the **OIBSIP Python Programming Internship** at **Oasis Infobyte**.

The internship focuses on learning Python through practical, project-based development. Throughout the program, I worked on Python applications that helped strengthen my understanding of programming fundamentals, problem solving, APIs, GUI development, data handling, and real-world software development.

Each project is organized in its own directory with its source code and documentation.

## About OIBSIP

OIBSIP is an internship program by Oasis Infobyte designed to provide students with practical exposure to technology through hands-on projects and learning.

## Repository

This repository serves as a collection of my internship work and learning progress throughout the program.

**Technologies:** Python, Tkinter, SQLite, APIs, Requests, Matplotlib, Pillow, and other Python libraries.
